# Age Calculator

A simple and responsive web application that calculates a user's age based on their date of birth. The project is built using HTML, CSS, and JavaScript 

## Features

- Calculate age from date of birth
- Displays age instantly
- Simple and user-friendly interface
- Responsive design
- Built with vanilla JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
AgeCalculator/
│── index.html
│── style.css
│── script.js
└── README.md
```

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/kainatmoin/Calculator.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

## How It Works

- Enter your birth **day**, **month**, and **year**.
- Click the **Submit** button.
- The application calculates and displays your current age.
